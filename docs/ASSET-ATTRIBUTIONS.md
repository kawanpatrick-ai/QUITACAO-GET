# Créditos dos elementos visuais

## Tema Madara — referências fornecidas pelo usuário

- As três artes de referência deste tema foram fornecidas diretamente na conversa do projeto.
- Os arquivos originais foram preservados visualmente e apenas redimensionados e codificados em WebP para reduzir o peso de carregamento:
  - `madara-sidebar.webp`: referência vertical de combate, usada atrás da navegação lateral.
  - `madara-banner.webp`: referência horizontal em close-up, usada no painel visual do cabeçalho.
  - `madara-moon.webp`: referência horizontal com silhueta e lua vermelha, usada como imagem ambiente do conteúdo.
- Nenhum personagem, rosto, armadura, pose, silhueta ou elemento central foi redesenhado. Os ajustes são restritos a recorte, escala, posicionamento e camadas de contraste da interface.
- O SVG anterior de olho foi removido para evitar substituir a referência visual por um símbolo genérico.
